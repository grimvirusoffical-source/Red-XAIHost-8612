# Red-XAI Agent Forge Runtime

Eight-role development team orchestrator designed for Railway.

## Runtime
- Lead Orchestrator
- Universal Programmer
- Sound Designer / Audio Engineer
- UI/UX Designer
- QA Tester
- Stress / Security Tester
- Builder / Release Engineer
- Exporter / Distribution Engineer

Set `OPENAI_API_KEY` in Railway secrets and optionally `OPENAI_MODEL`.
Run with `npm start`.

This branch is intentionally isolated from the Red-XAI Host main branch.
